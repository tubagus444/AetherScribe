# L05 - Perluasan TypeScript strict: backup dan Atlas

Tanggal: 15 November 2026. Source dasar `3f027fb`.

## Cakupan batch

Tambahkan delapan root implementasi ke tsconfig.strict.json. Tidak mengaktifkan
strict seluruh aplikasi atau menonaktifkan flag strict yang sudah berjalan.

| Root baru | Tanggung jawab |
|---|---|
| importRemap | Remap foreign key dan entitas proyek impor |
| backupIO | Pembacaan file/response, batas stream dan gzip |
| backupEnvelope | Perakitan envelope JSON backup |
| backupRetention | Kebijakan retensi backup |
| mapGeometry | Transformasi koordinat/geometri Atlas |
| atlasColors | Resolusi/validasi warna penanda |
| atlasAnalytics | Analisis wilayah dan kemunculan penanda |
| atlasHierarchy | Struktur portal, breadcrumb dan ringkasan sub-peta |

Semuanya berada di src/lib/. Empat import transitif tambahan ikut diperiksa:
backupLimits, blobCodec, backupValidation dan codexCategories. Tidak memakai stub
declaration atau mengecualikan dependensi tersebut untuk meloloskan pemeriksaan.

Pengaman compile-only baru, src/contracts/strict/backupAtlas.typecheck.ts,
memastikan hasil parsing backup tetap unknown (perlu validasi), Response tidak
boleh undefined, titik poligon tidak boleh null, koordinat harus lengkap/number,
dan centroid tetap mengharuskan penanganan hasil null untuk input kosong.

Penambahan satu root/berkas di luar 12 helper berasal dari pengaman compile-only

tidak termasuk angka source proyek. Cakupan aktual mengikuti program compiler,
bukan sekadar jumlah include pada konfigurasi.

## Diagnostik, pengecualian dan policy

Helper yang dipilih sudah memiliki tipe yang cukup untuk lulus strict. Tidak ada
diagnostik yang membutuhkan perubahan perilaku, penambahan cast/any/non-null,
atau directive penekan error. L05 mengaktifkan pemeriksaan dan mencegah regresi
pada modul tersebut; bukan mengklaim menemukan atau memperbaiki bug runtime baru.

Pada 12 helper tambahan masih terdapat escape lama:

- backupValidation: empat explicit any, dua type assertion.
- importRemap: tujuh explicit any, lima type assertion.
- atlasAnalytics: satu non-null assertion dan dua type assertion.
- backupLimits dan blobCodec: masing-masing satu assertion (termasuk as const).

Strict melarang implicit any tetapi tetap mengizinkan explicit any/assertion.
Itulah sebabnya maintenance policy mencatat budget lama per-file. Batas semua
38 file lama dibandingkan dengan policy HEAD dan dipastikan tidak berubah;
13 file baru memperoleh batas sesuai source yang diaudit. Tidak ada escape
tambahan di source implementasi. scopeUpdates mencatat alasan perluasan L05;
CI tidak meregenerasi atau menaikkan budget otomatis.

noUncheckedIndexedAccess, exactOptionalPropertyTypes dan strict global tetap
belum diaktifkan. skipLibCheck tetap mengikuti konfigurasi dasar; implementasi
proyek yang diimpor tetap diperiksa. React, proxy/dispatch, transport worker dan
layanan DB yang lebih luas tidak otomatis menjadi strict karena batch ini.

## Bukti dan verifikasi

Probe sementara pada atlasHierarchy dengan parameter tanpa tipe dan assignment
null ke string ditolak compiler (TS7006/TS2322). Explicit any baru ditolak
maintenance guard. Menghapus root atlasHierarchy hingga hilang dari program
strict juga ditolak guard. Source/config dipulihkan melalui finally setelah
setiap probe; command normal kemudian dijalankan kembali.

Typecheck umum/strict/maintenance, 90 berkas/787 tes dan build lulus lokal.
Peringatan build lama tentang chunk besar, eval ONNX dan Browserslist tetap ada.
Tidak menjalankan ulang browser/production/offline atau coverage pada L05 karena
tidak mengubah implementasi runtime. Bukti 35 browser tests pada L04 tetap
historis, bukan hasil pengujian ulang L05. CI menggunakan command yang sama;
belum mengklaim runner GitHub sudah memeriksa perubahan ini.

L05 selesai untuk batch ini; strict tetap perlu diperluas bertahap di masa depan
sesuai risiko/perubahan modul. L06 berikutnya mengukur jalur backup besar sebelum
memutuskan optimasi worker.
