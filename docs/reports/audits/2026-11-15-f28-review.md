## Pengaman pemeliharaan

Jalankan ketiganya:

```powershell
npm run lint
npm run lint:strict
npm run lint:maintenance
```

`scripts/check-maintenance.mjs` membaca `scripts/maintenance-policy.json` dan
menggagalkan check jika:

- Jumlah explicit any, non-null assertion, type assertion atau directive penekan
  error meningkat pada salah satu dari 38 berkas kontrak/helper/facade hasil
  refaktor. Budget per-file berasal dari kondisi yang diaudit, bukan seluruh app.
- Cakupan 28 berkas sumber strict menyusut, strict/noEmit dimatikan atau flag
  penting strict dinonaktifkan secara eksplisit. Import transitif dihitung, jadi
  menghapus satu root yang masih diimpor tidak otomatis berarti cakupan menyusut.
- Salah satu dari 18 nama ekspor publik facade AI hilang, termasuk ekspor tipe.
- Modul AI hasil ekstraksi mengimpor/mengekspor ulang facade melalui static import,
  yang dapat membuat dependensi melingkar dan state bersama sulit dilacak.

Detektor memakai AST TypeScript untuk tipe/assertion, scanner komentar untuk
directive, resolusi modul untuk import dan type checker untuk ekspor. String
berisi kata any/directive tidak dihitung. Self-check contoh positif/negatif
dijalankan setiap kali command dipanggil. Probe tambahan membuktikan peningkatan
any/assertion/non-null/directive, pengurangan cakupan strict, penghapusan ekspor
dan import internal ke facade semuanya ditolak. Source dipulihkan sesudah probe.

Budget ini mencegah kenaikan jumlah; mengganti satu escape lama dengan escape baru
dengan jumlah sama tetap perlu review semantik. Guard nama ekspor bukan bukti
kesamaan semua signature/perilaku; typecheck konsumen dan tes regresi tetap wajib.
Guard import hanya memeriksa static import/re-export modul internal yang terdaftar,
bukan bukti seluruh graf aplikasi bebas siklus. File baru perlu dimasukkan dalam
policy melalui review; check tidak otomatis mencakup semua source masa depan.
Jangan memperbarui budget otomatis di CI atau menaikkannya hanya untuk meloloskan
check. Penambahan/pengecualian harus disertai alasan dan tes yang relevan.

Konfigurasi CI Windows/Ubuntu menjalankan guard sesudah typecheck strict, sebelum
coverage/browser/build/production/offline. Eksekusi runner GitHub belum diverifikasi;
bukti di bawah berasal dari Windows lokal dengan Node 24.15.0.

## Audit struktur, ekspor dan dependensi

- Empat import yang dibuktikan tidak dibaca oleh compiler dihapus: ContextDepth
  pada facade AI, serta CodexEntry/RegionAnalytic/DrawMode pada AtlasPanel.
- Seluruh nama ekspor AI pada snapshot awal masih tersedia. Pemanggil fitur tetap
  memakai facade; state breaker/controller berada pada modul dispatch/execution.
  Tanggung jawab modul dijelaskan di [arsitektur](../../architecture.md).
- Tidak ada paket yang dihapus. Pemisahan file tidak membuktikan sebuah paket
  tak dipakai oleh fitur, build, server atau tes lain; tidak ada bukti cukup untuk
  menghapus dependensi. Versi TipTap, lockfile dan skema DB v34 tetap.
- Strict diperluas ke settings dan resultParsing: 19 root/28 source proyek,
  meningkat dari 17 root/26 source pada F28.3. Modul implementasi lain belum strict
  seluruhnya; skipLibCheck tetap berlaku pada declaration files dependensi.

## Verifikasi akhir lokal

Typecheck umum/strict, maintenance guard, 89 berkas/785 tes dengan coverage,
18 tes Chromium, data-path correctness/benchmark, build dan clean production
smoke, serta startup/offline lulus. Coverage V8: 32.11% baris, 31.95% statement,
25.35% branch dan 20.71% fungsi. Coverage tidak menggabungkan worker/browser/child
process native; belum ada threshold global. Artefak berada di coverage/ dan
test-results/ (diabaikan Git, diunggah CI sesuai workflow).

Peringatan build lama (chunk besar, eval ONNX, Browserslist) tetap ada. Instalasi
production menggunakan direktori sementara dan kredensial sintetis; tidak memakai
profil browser, naskah, kunci provider atau akun Drive pengguna.
