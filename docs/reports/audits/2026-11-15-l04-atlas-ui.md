# L04 - Interaksi Atlas melalui UI

Tanggal: 15 November 2026. Source dasar `b4500ba`.

Tambahkan enam skenario native Chromium di `e2e/atlasUi.spec.ts`. Fixture memakai
dua proyek, tiga peta, Codex dan penanda pada IndexedDB terisolasi. Semua aksi
upload, edit, tautan, navigasi dan pergantian proyek melewati panel aplikasi asli;
test tidak memanggil service Atlas untuk melakukan aksi yang diuji.

| Skenario | Bukti |
|---|---|
| Upload gambar | File SVG ditolak tanpa membuat peta; pilih PNG melalui tombol/input file, periksa satu peta dengan Blob/dimensi benar dan gambar tetap bisa dirender setelah reload |
| Edit area | Buka detail lewat kartu wilayah, seret vertex, sisip lewat midpoint, hapus lewat klik kanan, minimum tiga vertex tetap dijaga; geometri dan handle dipulihkan setelah reload |
| Edit rute | Alur edit yang sama dengan minimum dua vertex; hasil tidak hanya berubah di layar tetapi tersimpan di DB dan dibaca lagi setelah reload |
| Portal | Pilih sub-peta melalui dropdown, reload, masuk ke anak dan kembali ke induk; lepas tautan tanpa menghapus peta atau penanda |
| Deep-link Codex | Dari detail Codex pilih Lihat di Peta untuk penanda pada peta kedua; peta yang benar dan sidebar penanda terbuka, lalu Buka di Codex kembali ke detail entri |
| Ganti proyek | Beralih lewat ProjectManager, tutup modal dan buka Atlas proyek lain; peta/penanda lama tidak terlihat. Pin baru masuk ke projectId/mapId yang benar, geometri proyek lama utuh dan URL Blob lama dicabut |

Drag memakai mouse browser; sisip/hapus memakai elemen Leaflet asli. Pengujian
portal memakai tombol navigasi sidebar dan kembali ke induk, bukan double-click
ikon portal. Pemilihan file memakai Playwright filechooser.setFiles pada input
aplikasi, bukan otomatisasi dialog file OS secara manual.

URL.createObjectURL/revokeObjectURL dibungkus pada window test untuk melacak
keaktifan URL sambil tetap memanggil implementasi browser asli. Tidak mengganti
Leaflet, hook/service Atlas, decoder gambar atau IndexedDB. Request luar origin
diblokir dan AI local-only; tidak memakai profil, gambar, naskah atau akun pengguna.

## Hasil dan batas

Typecheck umum/strict/maintenance, 90 berkas/787 tes dan 35 tes Chromium lulus
lokal. Tidak ditemukan bug aplikasi baru dalam cakupan ini. Penyesuaian awal test
memakai aksi buka detail yang benar (double-click kartu), bukan menganggap satu
klik seleksi langsung membuka sidebar detail; modal pengelola proyek ditutup
sebelum interaksi berikutnya. Tidak mengubah source aplikasi, skema atau dependensi.
Build/production/coverage tidak diulang untuk perubahan tes dan dokumentasi.
Workflow test:e2e otomatis menemukan spec baru; belum memverifikasi run GitHub L04.

L04 melengkapi gap Atlas yang tercatat saat F28.5/F28.6. Bukti tahap sebelumnya
tetap historis; status terkini mengikuti ROADMAP dan testing.md. Lingkup yang
belum diuji mencakup seluruh format raster/resize/batas ukuran, file rusak,
double-click portal, portal siklik, setiap kombinasi filter/overlay, kegagalan
write geometri, browser lain dan semua keadaan pergantian tab/proyek. Snapshot
Blob/restore dan label inert tetap dijaga tes native sebelumnya. Hasil ini bukan
klaim seluruh permukaan Atlas bebas bug atau XSS.
