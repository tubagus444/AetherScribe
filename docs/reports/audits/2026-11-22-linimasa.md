# Verifikasi Linimasa dan Kalender, 22 November 2026

Pengujian lokal di Windows menggunakan Node 24.15.0, IndexedDB terisolasi, data cerita sintetis, dan Chromium headless. Lebar tampilan yang diuji adalah 1280 dan 390 piksel.

| Pemeriksaan | Hasil |
| --- | --- |
| Vitest | 852 tes lulus dalam 96 berkas. Cakupan mencakup pengelompokan 200 peristiwa, urutan era, rentang tanggal, remap karakter dan lokasi setelah impor proyek, serta pemulihan backup. |
| UI Linimasa | Lima skenario Chromium lulus. Ikhtisar muat secara horizontal pada kedua lebar, periode dan hari dapat dibuka, urutan dalam hari bisa diubah, serta detail dan label lama tetap tersedia. |
| Editor | Pilihan teks mengisi judul dan bab. Simpan dan batal mengembalikan fokus dengan seleksi dan isi naskah yang sama. Penautan karakter ke bab berikutnya tidak menghasilkan peringatan kemunculan dini. |
| Kalender dan kegagalan simpan | Peristiwa dibuat dari hari yang dipilih, dipindahkan melalui Linimasa dan muncul pada hari baru di Kalender. Draf tetap tersedia setelah target Codex terhapus selama pengisian. Proyek tanpa kalender bisa menyimpan peristiwa, membuat kalender, memberi tanggal, dan menghapus peristiwa. |
| UI data | Empat skenario Chromium tambahan lulus untuk restore penuh ke profil baru, impor proyek, penghapusan bab dan pelepasan referensi Codex. |
| Pemeriksaan kode | `npm run lint`, `npm run lint:strict`, dan `npm run lint:maintenance` lulus. Tes pengelompokan juga lulus saat dijalankan ulang setelah koreksi tipe fixture. |
| Build | Build produksi dan pembuatan service worker lulus. Vite melaporkan ukuran sebagian chunk di atas 500 kB dan Browserslist melaporkan data browser lama. |

Pada percobaan awal E2E ponsel, sidebar aplikasi yang terbuka menangkap klik. Tes diperbaiki untuk menutup sidebar melalui area luar seperti pada interaksi pengguna. Seluruh sembilan skenario Chromium terpilih lulus pada run akhir. Pemeriksaan TypeScript menemukan pelebaran literal kategori pada fixture 200 peristiwa, kemudian fixture diberi tipe `TimelineEvent` secara eksplisit.

Pengujian memakai viewport ponsel di Chromium, tanpa perangkat fisik. Provider AI dan Drive nyata, seluruh suite E2E lintas fitur, dan deployment produksi berada di luar verifikasi ini.

## Gulir horizontal pada tampilan awal

Lima skenario Chromium lulus pada pengulangan akhir. Fixture 200 peristiwa pada lebar 1280 dan 390 piksel memverifikasi perpindahan dengan roda mouse, panah kiri dan kanan, akses ke kartu terakhir, serta ringkasan yang muat pada layar. Pada lebar 390 piksel pengujian juga mengirim gestur sentuh melalui Chromium. Dua tes unit periode dan ketiga pemeriksaan lint lulus. Pada run pertama skenario editor mengalami timeout disertai galat stream berkas dari Playwright.

## Keterbacaan kartu dan kontrol

Pemeriksaan visual di Chromium 1280 dan 390 piksel memakai judul panjang serta dua kejadian per tanggal. Judul contoh terbaca dalam dua baris dan label bab terlihat pada baris tersendiri. Kartu dan titik aktif memakai aksen indigo. Setelah detail ditutup, posisi gulir horizontal tetap sama dan fokus kembali ke kartu.

Lima skenario Chromium dan ketiga pemeriksaan lint lulus. Pada percobaan awal, tes ponsel keliru mengharapkan garis waktu kosong saat memfilter Bab 5. Tes sebelumnya sudah memindahkan satu peristiwa ke Bab 5. Pengulangan memeriksa bahwa hanya peristiwa tersebut yang tampil. Pada satu pengulangan, dialog edit di skenario tanpa kalender terlepas dari DOM dan mengalami timeout. Pengulangan suite berikutnya lulus kelima skenario tanpa perubahan pada kode aplikasi.

## Refinement tampilan, 23 November 2026

Sebelum refinement, pengukuran pada posisi awal dan akhir menunjukkan jarak tepi kartu 6 piksel. Tata letak grid memberi kartu, titik, dan penghubung kolom yang sama. Deretan dengan lebar sesuai konten menyisakan 17 piksel di setiap ujung viewport saat mencapai batas masing-masing. Pengukuran ini konsisten pada lebar 1280, 820, 390, dan 320 piksel. Lebar halaman sama dengan viewport. Tampilan diperiksa melalui tangkapan Chromium pada keempat ukuran.

Enam skenario Chromium lulus. Fixture 200 peristiwa memeriksa posisi kartu pertama dan terakhir, koordinat titik dan penghubung, judul dua baris, jarak antarkartu, status panah, roda mouse, dan gestur sentuh. Pemeriksaan terpisah berhasil menggeser deretan 200 piksel dengan mouse. Tujuh tes pengelompokan dan ringkasan, tiga pemeriksaan lint, serta pemeriksaan diff lulus. Pemeriksaan browser memakai viewport emulasi.
