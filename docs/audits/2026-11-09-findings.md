# Register Temuan Audit — F01–F29

> **Tanggal:** 9 November 2026 (Asia/Jakarta). **Baseline:** `a47f895a47a633f02f95511192bddfa47397bef2`.  
> **Laporan:** [Analisis aplikasi](2026-11-09-application-audit.md). **Status pekerjaan:** [ROADMAP](../../ROADMAP.md#audit-2026-11-09).

Dokumen ini menyimpan bukti dan kriteria penerimaan, bukan tracker status kedua. Semua temuan merupakan hasil audit sebelum perbaikan. Baris merujuk baseline; tautan membuka file dan nomor baris dicatat terpisah agar dapat ditelusuri pada editor mana pun. Referensi tambahan yang disingkat berada dalam path modul yang disebut atau laporan utama.

**Metode:** source = penelusuran implementasi; mock = source asli dijalankan dengan dependency/DB/fetch terisolasi; build = hasil kompilasi aktual. Tidak ada klaim browser/IndexedDB nyata atau layanan eksternal sudah diuji. Probe audit tidak disimpan sebagai test suite; kriteria penerimaan di bawah adalah tes yang perlu dibuat/dijalankan saat implementasi.

**Prioritas:** P1 = risiko data/keamanan/fungsi inti yang perlu ditangani dahulu; P2 = correctness/reliabilitas berikutnya; P3 = perbaikan terencana. Tidak ada P0. **Effort:** S ≤1 hari, M 2–4 hari, L 5–10 hari; indikatif, termasuk tes terarah, bukan estimasi yang dapat dijumlahkan begitu saja.

## F02 — Proxy melampaui batas localhost

**Finding ID:** F02  
**Severity:** High  
**Recommended Priority:** P1  
**Module:** Express proxy  
**File:** [server.ts](../../server.ts)  
**Line:** 26, 50–95, 285–290, 325

**Description:** Server bind seluruh antarmuka; caller tidak dibatasi; key environment dan URL Ollama dipakai dari jalur request.

**Evidence:** listen pada 0.0.0.0; fallback key env; base URL Ollama berasal dari body. Suffix endpoint dibentuk server, bukan akses bebas semua path.

**Impact:** Caller yang menjangkau server dapat menggunakan kuota key dan memicu request ke tujuan lain. Firewall/LAN/internet exposure belum diperiksa.

**Recommendation:** Default bind 127.0.0.1; validasi Host/Origin sesuai origin lokal; allowlist tujuan/protokol Ollama dan pertimbangkan redirect. Pairing sederhana hanya jika LAN sengaja didukung.

**Confidence:** Tinggi untuk implementasi; exposure aktual unknown.  
**Verification Method:** Analisis route/config tanpa pemindaian jaringan.

**Effort:** S–M  
**Dependency:** F18 dapat dikerjakan satu batch; dokumentasikan kebutuhan Ollama remote.  
**Risiko perubahan:** Sedang: endpoint Ollama/LAN yang sebelumnya bebas mungkin perlu konfigurasi eksplisit.

**Kriteria penerimaan:** Default hanya loopback; target di luar allowlist ditolak termasuk redirect yang tidak diizinkan; caller tidak sah tidak dapat memakai key server; konfigurasi lokal normal tetap berfungsi.
